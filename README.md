### 🌱 이렇게 경험을 쌓았습니다

- **팀 프로젝트에서 고객 관리와 대시보드 개발**  
  [이커머스 백오피스](https://github.com/maschemy/eCommerceBackOffice)에서 고객 검색·필터·페이징, 상태 변경과 Soft Delete, 매출·주문 등 운영 통계 API를 담당했습니다.
- **인증을 포함한 API 개발 학습**  
  [일정 관리 API](https://github.com/maschemy/todoList2)를 통해 세션 기반 인증, 일정·댓글 관리, 입력값 검증과 예외 처리를 학습했습니다.
- **개발한 서비스를 배포하는 과정 실습**  
  [AWS 배포 프로젝트](https://github.com/maschemy/aws)에서 EC2·RDS 연결, S3 이미지 업로드와 Presigned URL, Docker와 GitHub Actions를 활용한 배포를 실습했습니다.
